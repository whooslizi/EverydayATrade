# Everyday a Trade

A poorly coded, pixel-induced retro survival simulator where yesterday’s tech billionaire becomes today’s sidewalk hustle hero.

**Live demo:** [https://everyday-a-trade.vercel.app/](https://everyday-a-trade.vercel.app/)

## What is this?

A simple project written in React + TypeScript + Vite, featuring a nostalgia-heavy pixel art aesthetic. You play as a former tech billionaire who lost everything overnight due to a stock crash and getting scammed. With only 100,000 VND and a stray dog named Dũng, you have 14 days to pay off a massive 20,000,000 VND debt to the notorious Cụ Bá.

If you fail to pay the daily interest or the full debt before the deadline, you lose everything. Will you survive the brutal reality of the sidewalk economy?


## How to play locally

1. Clone the repository:
   ```bash
   git clone https://github.com/whooslizi/EverydayATrade.git
   ```
2. Navigate to the project folder:
   ```bash
   cd EverydayATrade
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
